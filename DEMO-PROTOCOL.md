# Протокол демонстрации

Цель. Показать на одном PR, что критерий «сборка и тесты проходят» из §9 ТЗ ANDERSEN выполняется при оставшемся дефекте, и как это закрывает контрольный тест.

Дефект внесён вручную и служит иллюстрацией границы показателя. Качество какого-либо сервиса он не оценивает.

Дефект. В processUpdateForm удалена проверка даты рождения в будущем. Проверка при создании питомца не изменена.

Контрольный тест processUpdateFormWithFutureBirthDate. На исходной версии должен проходить, на версии с дефектом падать на attributeHasErrors("pet").

Патч ИИ. Идентификатор модели и промпт фиксируются здесь до генерации, сессия новая, без доступа к этому протоколу. Число генераций 1, публикуется результат единственной попытки. После генерации фиксируется SHA256 патча.

Свидетельства. Журналы GitHub Actions по каждому коммиту.

Модель Claude Sonnet 5.5 в приложении claude.ai, новый чат в режиме инкогнито, без памяти и без доступа к этому протоколу. Дата генерации 06.11.2026. Промпт приведён дословно ниже.

Ты разработчик Java и Spring. В методе processUpdateForm контроллера PetController при редактировании питомца принимается дата рождения в будущем, форма не возвращает ошибку. При создании питомца такая проверка есть. Предложи исправление метода processUpdateForm в виде unified diff для файла PetController.java. Выведи только diff, без пояснений.

К промпту прикладывается без изменений текст метода processUpdateForm из файла PetController.java в коммите 5e5b03a. Промпт и метод отправляются одним сообщением.
